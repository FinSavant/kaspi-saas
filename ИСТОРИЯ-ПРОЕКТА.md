## Что сделано и проверено на реальных данных

- **Накладные**: склейка только из вкладки «Передача», только по кнопке; термопринтер
  100×150 (по умолчанию), A4 по 4 и 8; сортировка по названию товара по умолчанию;
  фильтры по городам, товарам, заказам; несколько магазинов в один PDF; история и пересборка.
- **Демпинг-бот**: включается галочкой на конкретном товаре, минимальная цена вручную,
  никогда не опускается ниже неё; цену меняет через кабинет Kaspi. Фильтры
  «бот включён / выключен / открытые карточки», сортировки. Автосохранение полей.
- **Аналитика**: периоды сегодня / вчера / 7 / 30 / 90 дней / год / свои даты; 8 вкладок.
  Прибыль = выручка − себестоимость − комиссия категории − НДС 16% на комиссию −
  Kaspi Pay 0,95% − фактическая доставка. Совпадает с WaybillPrint до 1 ₸.
  Продажа = выданный заказ (COMPLETED). Вкладка «В пути» — нереализованная прибыль.
  Цветные таблицы, сортировка и фильтр «только в минусе».
- **Несколько магазинов**: «Настройки» → «Магазины» → «Добавить магазин».
- **Ежедневный отчёт в Telegram в 09:10**: новые заказы, выдано, сколько поступит на счёт,
  прибыль, в пути, демпинг-бот (первые по цене, дошли до минимальной цены),
  товары с остатком ≤ 3 шт.

## Важные решения и чему научились

- **Официальный API Kaspi** (`kaspi.kz/shop/api/v2`, токен) даёт заказы и накладные,
  но не даёт список товаров и не меняет цены. Это делается через кабинет продавца
  отдельным пользователем по email с правом «Загрузка товаров».
- **Витрина Kaspi блокирует серверы в дата-центрах** (ответ 405). Поэтому цены
  конкурентов читает компьютер (`start-price-reader.cmd`), а сервер по ним решает
  и меняет цены. Обходить блокировку через прокси и подделку браузера не стали —
  риск блокировки магазина.
- **Заказы в «Передаче»** = Kaspi Доставка + собран + есть накладная + ещё не передан курьеру.
- **Сообщения клиентам (автоответы)** — отложено. API чата в кабинете найдено
  (`mc.shop.kaspi.kz/chats/api/mobile`), но оно работает только при входе по телефону,
  а права на чат для пользователя по email в Kaspi нет. Варианты на будущее:
  расширение Chrome, работающее во вкладке кабинета, или вход сервера по телефону.
- **WhatsApp** — только через официальный API Meta (бизнес-аккаунт, отдельный номер,
  платные шаблоны). Неофициальные сервисы рискуют блокировкой номера.

## Как обновить сервер после изменений кода

Попросить Claude: «выложи изменения на сервер». Технически: архив кода → `scp` →
`bash /opt/kaspi-saas/deploy/server/up.sh` (пересобирает и перезапускает всё).
Воркер (меняет цены) после смены схемы базы запускается командой:

```bash
ssh -i $env:USERPROFILE\.ssh\kaspi_vps root@89.126.194.84 "bash /opt/kaspi-saas/deploy/server/worker.sh"
```
