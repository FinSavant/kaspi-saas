# SANQ (kaspi-saas)

Сервис для продавцов Kaspi.kz — https://sanq.kz. Робот цен (демпинг-бот), точная аналитика прибыли, склейка накладных, сборка заказов, предзаказ, автоматические просьбы об отзывах и ежедневный отчёт в Telegram. Подписка по тарифам, вход по email и паролю или через Telegram.

## Структура

```
packages/
  db/            Prisma-схема (PostgreSQL) и клиент
  core/          чистая логика: тарифы, цены, склейка PDF, аналитика, шифрование
  kaspi-client/  Kaspi Merchant API, кабинет продавца, витрина
  storage/       хранилище PDF: локальная папка или Google Cloud Storage
apps/
  api/           Fastify: товары, накладные, аналитика, вход, тарифы, админка
  worker/        BullMQ: робот цен, синхронизация товаров и заказов, отзывы, отчёты
  bot/           Telegraf: отчёт в 09:10, /report, /print, вход через Telegram
  web/           Next.js: лендинг (ru/kz), кабинет, админка
deploy/server/   Docker Compose, Caddy (HTTPS), up.sh, worker.sh, cleanup.sh
scripts/         add-shop, mc:login, price-reader, sync-orders, check:kaspi
```

## Тарифы и пробный период

Новый аккаунт получает **5 дней** (`TRIAL_DAYS` в `packages/core/src/plans.ts`) со всеми функциями. Срок уже созданных пробных аккаунтов не меняется. После окончания вход закрывается страницей «обновите тариф» со ссылкой на WhatsApp, робот останавливается, данные сохраняются.

| Тариф | Цена, ₸/мес | Магазины | Робот / предзаказ |
|---|---|---|---|
| Старт | 9 900 | 1 | 50 / 50 |
| Pro | 15 900 | 2 | 120 / 120 (отзывы входят) |
| Только отзывы | 4 999 | 1 | — |
| Только аналитика | 5 990 | 1 | — |

Дополнение «отзывы» к Старту — 4 999. Оплата переводом через WhatsApp (`SANQ_WHATSAPP`); после оплаты владелец продлевает доступ в админке.

## Кабинет

Вкладки: Главная, Накладные, Сборка, Робот цен (товары, цены, склады, предзаказ; колонка «Себестоимость + %» — справочная цена с вашим процентом прибыли, робот ориентируется на «Мин. цену»), Отзывы, Аналитика, Тарифы, Настройки. На каждой вкладке значок «?» с короткой инструкцией. Раздел Wildberries виден только владельцу платформы (в разработке).

### Аналитика

Периоды: «Сегодня», «Вчера», **«Тек. месяц»** (с 1-го числа по сегодня), **«Пред. месяц»**, 7 / 30 / 90 дней, год и свои даты. Кнопка **«Сравнить с предыдущим периодом»** показывает таблицу: проданные штуки, заказы, выручка, средний чек, чистая прибыль — сейчас, раньше, разница и процент. Для «Тек. месяц» сравнение идёт с теми же днями прошлого месяца, для «Пред. месяц» — с месяцем до него, для остальных периодов — с таким же по длине периодом перед ним.

Вкладки: Обзор, Выручка, Товары, География, Доставка и оплата, Прибыль, В пути, Отмены. Оформление: градиентные графики с подсказками, кольцевая диаграмма «Структура прибыли», карточки показателей с динамикой, таблицы с подсветкой (`apps/web/components/charts.tsx`).

- **Продажи** — только выданные заказы (`COMPLETED`).
- **Прибыль** = выручка − себестоимость − комиссия категории − НДС на комиссию (16%) − Kaspi Pay (0,95%) − налог и свои расходы (проценты от выручки) − фактическая доставка. Ставки комиссий — `scripts/kaspi-commissions-2026.ts` (`npm run seed:commissions`).
- **«В пути»** — нереализованная прибыль по заказам в работе.

### Админка (`/admin`, только владелец)

«Продавцы и подписки»: таблица с поиском, фильтрами (все / пробные / оплаченные / закрытые), цветными статусами, кнопка «Назад». Смена тарифа, «отзывы», дата «оплачено до», «+1 месяц», удаление пустого аккаунта.

## Накладные

Склейка — по кнопке «Склеить накладные» (или `/print` в Telegram). В неё попадают заказы вкладки «Передача» кабинета Kaspi (`KASPI_DELIVERY`, собран, есть накладная, не передан курьеру). Форматы: термопринтер 100×150, A4 по 4 или 8; сортировка и фильтры; несколько магазинов в один PDF; история и пересборка. Склейки хранятся 24 часа.

## Подключение магазина

Официальный API Kaspi (токен) даёт заказы и накладные, но не товары и не цены. Их даёт кабинет продавца. Вход в кабинет — по **номеру телефона** (SMS-код) или по email пользователя с правом «Загрузка товаров»; сессия хранится зашифрованной. Чат с покупателями для отзывов открывается только входом по телефону (Настройки → «Чат с покупателями»). Устаревшая сессия: `npm run mc:login` или вход в Настройках.

## Цены конкурентов

Витрина Kaspi блокирует адреса дата-центров, поэтому цены читает **компьютер владельца**: `start-price-reader.cmd` (`scripts/price-reader.ts`, автозапуск в «Автозагрузке» Windows) забирает задачи с сервера и отправляет цены обратно через `https://sanq.kz/api/reader/*`. Сервер работает с `COMPETITOR_SOURCE=remote` и решает цену по этим данным. Обход блокировки через прокси не используется.

## Запуск локально

Нужны Node.js 22+ и Docker Desktop (PostgreSQL и Redis).

```bash
npm install
cp .env.example .env
docker compose up -d
npm run db:migrate
npm run dev:api     # и отдельно: dev:worker, dev:web, dev:bot
```

## Выкладка на сервер

Сервер: hoster.kz, Ubuntu, `/opt/kaspi-saas`, Docker Compose, Caddy с HTTPS для sanq.kz. Выкладка запускается с компьютера владельца:

1. Закоммитить изменения, затем собрать архив: `git archive --format=tar.gz -o ..\sanq-deploy.tgz HEAD` (архив — родительская папка проекта).
2. Запустить `deploy-sanq.cmd` (вызывает `deploy-sanq.ps1`): копия базы в `/opt/backups/kaspi-ГГГГММДД-ЧЧММ.dump` → загрузка архива → распаковка → `deploy/server/up.sh` (пересборка и перезапуск, уборка Docker).
3. Журнал — `deploy-sanq.log`. Секреты лежат только в `.env` (компьютер) и `.env.server` (сервер), в Git их нет.

Кроме того, `deploy/server/cleanup.sh` — ежедневная уборка сервера (старые копии базы, кэш сборки); тома Docker не трогает.

## Известные ограничения

- Нет подтверждения email и восстановления пароля; вход резервный — через Telegram.
- Копии базы лежат на том же сервере, что и сама база.
- Раздел Wildberries не закончен и скрыт от продавцов.
- Передача заказов (вкладка «Передача» как отдельное действие) в разработке и в этот релиз не входит.
- Полный разбор по истории решений — в `ИСТОРИЯ-ПРОЕКТА.md`.
